# 工作周记

一个原生 macOS 工作记录工具。每天随手记录工作内容，到周末一键按项目或按日期生成 Markdown 周报。

## 功能

- 按日期记录工作内容、所属项目和完成状态
- 查看最近十周记录及每周进度概览
- 编辑、删除已有记录
- 一键生成周报，支持按项目或按日期汇总
- 使用用户自定义的第三方 AI API，将零散关键词润色为几段自然的简短报告
- 支持 Chat Completions 与 Responses 两种兼容接口格式
- 模型名称支持下拉选择和手动输入；Gemini 地址可自动识别并从接口刷新可用模型
- 自动保存生成或编辑后的周报，再次打开同一周时继续编辑
- 添加下周计划，复制到剪贴板或导出 `.md` 文件
- 设置中可单独清除周报缓存，或清除全部周报与工作记录，两种操作均需再次确认
- 自动保留最近 4 周的周报和最近 10 周的工作记录
- 数据仅保存在本机 `~/Library/Application Support/WeeklyWorkLog/worklog.json`

## 自定义 AI

在应用左下角进入“周报设置”，填写第三方服务提供的完整 API 地址、模型名称、接口格式和认证方式。应用不会内置或默认请求任何 AI 厂商；只有点击“生成自然周报”后，才会把当前周的工作记录发送到用户配置的地址。

API 密钥保存在本机的 `worklog.json` 中，应用不会访问 Apple 钥匙串，因此不会触发系统密钥授权提示。该文件未加密，请妥善保护本机账户和文件权限。未配置 AI、接口不可用或请求失败时，本地汇总功能仍然可以正常使用。

## 构建与运行

本机需要 macOS 13 或更高版本，以及 Swift 6 命令行工具。

```bash
./Scripts/build-app.sh
open "dist/工作周记.app"
```

也可以在开发模式下运行：

```bash
swift run WeeklyWorkLog
```

运行测试：

```bash
swift test
```

应用使用临时本地签名。首次从其他电脑运行时，可能需要在“系统设置 → 隐私与安全性”中允许打开。
